# v0.1.29 发布验收

2026-11-22 在小米平板 25091RP04C、Android 17（API 37）上验证，录屏目标为抖音极速版。

## 单击返回 SBS

设备开启「授权前台识别」后，仅通过系统录屏弹窗选择抖音。应用自动记下 `com.ss.android.ugc.aweme.lite`。
回到桌面后分别在普通 SBS、MiDaS 和 Depth Anything V2 模式下单击悬浮球，均返回同一个抖音任务并恢复全屏 SBS。
核对了桌面与抖音的前台窗口、SBS 覆盖层和画面，同一轮前后仍为原单应用录屏会话。

## 3D 闪退和左右眼输出

旧版 v0.1.28 将 MiDaS 设为 480P 后，在 TensorFlow Lite JNI 的 `allocateTensors` 触发原生 SIGSEGV。
设备实际使用 4 KiB 页。修正后直接按模型声明的固定尺寸推理，并把推理移到工作线程。

| 模式 | 平板上的实际结果 |
| --- | --- |
| 普通 SBS | 两张截图对齐中心距后，分别有 205/206、197/200 个匹配区域的左右偏移为 0 像素。 |
| MiDaS | 256×256 输出。首次获得有效深度约 147 ms。复测截图中有 158/159 个匹配区域的绝对左右视差至少为 2 像素。 |
| Depth Anything V2 | 518×518 输出。切换后的首个有效深度约 3.24 s，之后连续两张截图均有深度视差。其中一张有 182/186 个匹配区域的绝对左右视差至少为 2 像素。 |

正式 APK 在同一进程内完成两模型切换，并切回 MiDaS 复测。该进程在测试期间无新增崩溃或 ANR 退出记录。
截屏、前台窗口记录、旧版原生崩溃栈和视差计算记录保存在本机 `.local/verification/sbs-3d-tablet-20261122/`。
