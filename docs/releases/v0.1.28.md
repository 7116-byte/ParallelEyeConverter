# v0.1.28 发布验收

2026-11-22 在 Android 17 平板 25091RP04C 上验证。复用抖音极速版的单应用录屏，在同一采集会话中完成四轮横转竖，其中一轮在视频播放中完成。每次均恢复到 1068×1600 的竖屏采集，原先从 x=443 像素开始的偏移和裁切未复现。视频播放中的两张竖屏截图显示原接缝两侧都在更新。

v0.1.27 先调整虚拟屏幕尺寸再绑定新 Surface，可能使系统按旧横屏 Surface 计算镜像位置。修正同时应用于正常切换和失败后的旧 Surface 回绑。真机以分屏截图和虚拟屏幕截图为准，避免将系统图层转储中滞后的边界当成实际输出。

真机使用带修正的 v0.1.27 测试包，正式包版本号升级至 v0.1.28 / 29。离线构建与 Lint 通过，0 个错误、25 个原有警告。包名、原签名、模型哈希及未压缩打包均通过校验。
